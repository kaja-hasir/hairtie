# Hair Tie
A minimal FiveM script that adds a hair tie item, allowing players to switch to a hairstyle that works better with masks and hats.

*Don't worry it handles special cases and never prints anything*

![Hairite Demo](hairtie.gif)

## Requirements
- ox_inventory

## Use
1. `ensure hairtie` in the server.cfg of the server
2. Select **ONE** image that you like in `inventory/image_you_select/`, and place it into `ox_inventory/web/images/`
3. Open and modify to your language the `inventory/item/item.lua`, choose the right image name you selected in 2., and place it into `ox_inventory/data/items.lua`
